= Entity component system (ECS)

Entity component system (ECS) is an xref:architectural-pattern.adoc[*architectural pattern*] that is
widely used in game development.

ECS follows the xref:composition.adoc[*composition over inheritance*] principle. Every object in a
game's scene is an *entity* – enemies, weapons, bullets, buildings, etc. – and each entity is
*composed* from *components* that determine the entity's behavior, functionality, and other
characteristics.

The behavior of an entity can be changed at runtime by adding or removing components. Thus, the
*system* runs continuously and performs global actions on every entity.

ECS architecture is often combined with xref:data-oriented-design.adoc[*data-oriented design*]
techniques.
