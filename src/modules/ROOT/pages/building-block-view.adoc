= Building block view

The *building block view* is an xref:architecture-view.adoc[*architecture view*] that shows the static structure of a
system – how its xref:building-block.adoc[*building blocks*], and ultimately its source code, are organized. It is
usually presented hierarchically, starting from the system's xref:context-view.adoc[*context view*] and decomposing
each building block into its own constituent building blocks, one level at a time.

Because it shows structure rather than behavior, the building block view is typically complemented by one or more
xref:runtime-view.adoc[*runtime views*], which show how those same building blocks cooperate at runtime in concrete
scenarios.
