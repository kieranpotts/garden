= Extract, transform, load (ETL)

ETL stands for Extract, Transform, Load. It is a data integration process that
combines data from multiple sources into a single, consistent data store. This
process involves extracting data from source systems, transforming it into a
usable format, and loading it into a target system, often a data warehouse. ETL
ETL is a foundational process in xref:big-data.adoc[*big data*] pipelines, feeding
data warehouses and data lakes. For near-real-time integration,
*xref:change-data-capture.adoc[change data capture]* offers a streaming
alternative to batch ETL.
