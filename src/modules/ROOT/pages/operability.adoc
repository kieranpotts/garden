= Operability

*Operability* is the degree to which a product or system has attributes that make it easy for operators to run,
monitor, and control. It is a xref:quality-attribute.adoc[*quality attribute*] and, per ISO/IEC 25010, a
sub-characteristic of xref:usability.adoc[*usability*]. Usability is generally framed around the end user, whereas
operability is framed around the people who run and administer the system.

A system's operability shows up in things like clear xref:logging.adoc[*logging*] and xref:monitoring.adoc[*monitoring*],
predictable configuration, sensible defaults, and tooling that lets an operator diagnose and recover from problems
without special knowledge of the internals. It's a concern shared with
xref:site-reliability-engineering.adoc[*site reliability engineering*], which treats how easy a system is to operate
as directly related to how reliably it can be run in production.
