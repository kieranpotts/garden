= Self-contained system (SCS)

A self-contained system is a
xref:software-architecture.adoc[software architecture] that focuses on
separation of functionality into many independent systems. The complete logical
system is a collaboration of many smaller, self-contained software systems.

An SCS typically owns its own front-end, making the pattern a close relative of
xref:micro-frontend.adoc[*micro front-ends*].
