= Transactions

// TODO: https://newsletter.systemdesignclassroom.com/p/transaction-isolation-and-read-and-write-anomalies

A database transaction is a sequence of operations that are treated as a single unit of work and are completed together, ensuring xref:data-integrity.adoc[data integrity].

The xref:acid-principles.adoc[ACID principles] are a set of properties of database management systems that guarantee that database transactions reliably maintain data integrity.

See also xref:distributed-transaction.adoc[distributed transaction].
