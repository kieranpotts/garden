= Continuous deployment

Continuous deployment is an advanced software delivery *[practice]* in which
every change that goes through an automated xref:deployment-pipeline.adoc[*delivery pipeline*] gets put into
production automatically.

Continuous deployment allows for multiple updates to production services to be
made every working day.

Continuous deployment is particularly effective in the context of
xref:cross-functional-teams.adoc[*cross-functional teams*] that are responsible
for the entire software delivery process, from design and development to
deployment and operation in production. Continuous deployment enables teams to
deploy changes, monitor the changes in production, and roll back, revert, or
abort deployments if necessary. A xref:rolling-deployments.adoc[*rolling deployment*]
is a common mechanism for pushing each change to production without taking the
service offline.
