= Quantization

*Quantization* is a technique for reducing the numerical precision of a model's xref:model-weights.adoc[*weights*], for example representing values with 4-bit integers instead of 16-bit or 32-bit floats. This reduces the model's memory footprint and speeds up xref:inference.adoc[*inference*], at the cost of a small reduction in output quality.

Quantization is what makes it practical to run a xref:large-language-model.adoc[*large language model*] on consumer hardware with limited VRAM. Together with the parameter count, the quantization level determines how much memory the weights occupy, and so whether an xref:open-weight-model.adoc[*open-weight model*] will load on a given machine at all.

Some xref:model-runtime.adoc[*model runtimes*], such as llama.cpp, are designed around running quantized models. The same model may also be served at different quantization levels by different xref:inference-provider.adoc[*inference providers*], which is one reason its quality can vary from one provider to the next.
