= Container

A container can be thought of as a lightweight xref:virtual-machine.adoc[*virtual machine*]. Unlike
a virtual machine, which loads a full operating system, a container shares a kernel with the host
OS. Native features of the host OS are used to create a virtual environment for the containerized
application to run in, creating a similar degree of xref:isolation.adoc[*isolation*] as a VM, but
with much less overhead.

See xref:containerization.adoc[*containerization*] and xref:virtualization.adoc[*virtualization*]
for more notes on the differences between containers and VMs. See also
xref:container-orchestration.adoc[*container orchestration*], xref:docker.adoc[*Docker*],
xref:hypervisor.adoc[*hypervisor*], and xref:sandbox.adoc[*sandbox*].
