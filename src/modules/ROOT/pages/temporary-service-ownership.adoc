= Temporary service ownership

*Temporary service ownership* is a short-term way of making changes to a service that has no regular owner. A team that needs to change the service takes on its ownership for the duration of the work, then relinquishes it. The service typically reverts to being an xref:orphaned-service.adoc[*orphaned service*].

While the team holds ownership, it controls who may change the service and coordinates with any other teams working on the same code base. Being the owner means being responsible for the changes made to it.

The model suits a burst of changes by a single team in a short period. It is an alternative to xref:open-service-ownership.adoc[*open service ownership*], and is a better fit where letting anyone change the service is a worry, or where one team is changing it heavily and more contributors would get in each other's way.

== Limitations

Ownership that changes hands often makes it hard to hold a consistent vision for the code base as it evolves, and the result can be messy. The problem is less serious the smaller the code base is.

A xref:roving-custodian.adoc[*roving custodian*] is another way of handling changes to an orphaned service, using gatekeepers who aren't in a dedicated team.
