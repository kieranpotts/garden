= Algorithms

Algorithms are step-by-step procedures or formulas for solving problems. Common
algorithms include sorting algorithms (like quicksort and mergesort), searching
algorithms (like binary search), and graph algorithms (like Dijkstra's shortest
path).

*xref:data-structures.adoc[Data structures]* and algorithms (DSA) are
foundational topics in *xref:computer-science.adoc[computer science]*.
