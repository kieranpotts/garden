= Continuous integration

Continuous integration is a software development *[practice]* where members of a
team integrate their work at regular intervals, typically at least once a day.

It is realized through *xref:commit-early-commit-often.adoc[commit early, commit
often]*, the habit of saving work in small, frequent increments.

Continuous integration is a prerequisite for
*xref:continuous-delivery.adoc[continuous delivery]* and
*xref:continuous-deployment.adoc[continuous deployment]*.
