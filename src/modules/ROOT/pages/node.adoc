= Node

In xref:uml.adoc[*UML*] deployment diagrams, a *node* is a processing resource — a physical or virtual machine,
execution environment, or application server — onto which software artifacts are deployed and executed. It
represents the runtime hardware or platform a system runs on, as distinct from the components and artifacts it
hosts.

// See also deployment views, etc.

In web development, "Node" is shorthand for Node.js, an open-source xref:javascript.adoc[*JavaScript*] runtime built
on Chrome's V8 engine. Node.js is known for its event-driven, non-blocking I/O model, which lets a single-threaded
process handle many concurrent connections cheaply, and for its extensive package ecosystem.
