= Integrity

As a xref:quality-attribute.adoc[*quality attribute*], *integrity* is the degree to which a system prevents unauthorized
access to, or modification of, its programs or data. ISO/IEC 25010 classifies it as a sub-characteristic of
xref:security.adoc[*security*], alongside confidentiality and non-repudiation, and it is the "I" in the *CIA triad*.

Integrity is achieved by controls such as *access restrictions* and *cryptographic* techniques like *digital signatures*,
which let a system detect whether data or code has been tampered with.

This security sense is narrower than xref:data-integrity.adoc[*data integrity*], which also covers accidental
corruption and logical validity, not just unauthorized modification.

A related, behavioral sense of integrity concerns whether a system behaves coherently and reproducibly, whether clients
get identical results for identical queries, which overlaps with xref:consistency.adoc[*consistency*] rather than
with security.

The term is therefore context-dependent. Which definition applies depends on whether the conversation is about protecting
data from an attacker or about a system behaving predictably.
