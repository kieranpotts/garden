= Agent transcript

An *agent transcript* is the record of an agent session that an xref:agent-harness.adoc[*agent harness*] may keep for *auditability*. It holds the full sequence of user inputs, model outputs, and tool calls and their results, in order. Most harnesses assign each session an identifier and persist its transcript to disk, which is what allows a session to be resumed later.

A transcript is distinct from the model's context. The context is mutable during a session. The harness may trim, clear, or *compact* it to stay within the context window, so what the model sees at any moment is usually a subset of what happened. The transcript is the complete, unedited history, and it is the primary source against which a compacted summary can be checked.

Transcripts are useful for reviewing what an agent actually did, debugging why it went wrong, and mining past sessions for lessons to feed back into rule files and skills. They are also a security concern. A transcript can contain secrets the agent read, file contents, and anything a tool returned, so it should be protected like any other log that holds sensitive data.
