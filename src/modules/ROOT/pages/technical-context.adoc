= Technical context

*Technical context* shows a system as a single xref:black-box-view.adoc[*black box*] within its environment, seen from
a technical or deployment perspective. It documents the concrete interfaces and communication channels the system
uses, together with the relevant technical details of its neighboring systems — the protocols, ports, and formats
that carry data across the system's boundary.

Where the xref:business-context.adoc[*business context*] names the same neighbors and interactions in domain terms,
technical context supplements that view by mapping each domain-specific interaction onto the specific communication
channels and technical protocols that implement it. Business context and technical context together make up the
xref:context-view.adoc[*context view*] in the xref:arc42.adoc[*arc42*] architecture documentation template.
