= Asynchronous processing

The term asynchronous processing refers to any strategy in which the processing
of some tasks does not block the processing of other tasks.

Asynchronous processing may be implemented within a
xref:monolith.adoc[*monolith*] using xref:concurrency.adoc[*concurrency*] and
xref:parallelism.adoc[*parallelism*] (ie.
xref:asynchronous-programming.adoc[*asynchronous programming*]), or by passing
xref:asynchronous-communication.adoc[*asynchronous messages*] between programs
running on multiple systems.

Asynchronous processing is the foundation of
xref:reactive-programming.adoc[*reactive programming*] and
xref:message-driven-architecture.adoc[*message-driven architecture*], and is
widely used in xref:distributed-system.adoc[*distributed software*] to improve
performance and scalability. A *xref:task-queue.adoc[task queue>* is a common
implementation pattern for asynchronous processing in distributed systems,
offloading units of work to background workers.
