= Traceability

Traceability is the ability to follow the relationships between artifacts
across a development lifecycle — for example, linking a design element back
to the requirement that motivated it, or a test case back to the requirement
it verifies.

In model-based systems engineering, the *xref:sysml.adoc[Systems Modeling
Language (SysML)]* codifies this through explicit satisfy, verify, refine,
and derive relationships between requirements and the blocks that realize
them.
