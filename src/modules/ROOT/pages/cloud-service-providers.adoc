= Cloud service providers (CSPs)

xref:cloud-computing.adoc[*Public cloud computing*] services are supplied by
Cloud Service Providers (CSPs). The three hyperscale CSPs are Amazon Web
Services, Microsoft Azure, and xref:google-cloud-platform.adoc[*Google Cloud
Platform*]. The networking rows in the table below – VPC, DNS, load balancing,
and firewall – are the building blocks of xref:cloud-networking.adoc[*cloud
networking*].
