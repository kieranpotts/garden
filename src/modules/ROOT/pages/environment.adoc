= Environment

A system's *environment*, per ISO/IEC/IEEE 42010, is the context that determines the setting and circumstances of all
the influences acting upon that system. It is everything with which a system exchanges data, control flow, or effects,
without itself being part of the system.

The environment of a software system is broader than its immediate technical surroundings. It includes developmental,
technological, business, operational, organizational, political, economic, legal, regulatory, ecological, and social
influences — anything outside the system's boundary that shapes what it must do or how it must behave.

A system's xref:context-view.adoc[*context view*] documents this boundary, showing the system as one black box
within its environment and naming the neighbors — other software, hardware, humans, or organizations — it interacts
with.
