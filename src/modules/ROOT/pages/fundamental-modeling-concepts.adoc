= Fundamental Modeling Concepts (FMC)

:link-fmc: http://fmc-modeling.org/

*Fundamental Modeling Concepts (FMC)* is a graphical notation for modeling and documenting software systems,
independent of any particular programming language, methodology, or tool. It aims to describe a system's
structure — its components and how they relate — rather than its behavior over time, which is the concern of
notations such as UML sequence diagrams.

FMC's own site frames its goal as description rather than execution:. The notation exists to make a system's
architecture legible to a human reader, not to be simulated or compiled.
