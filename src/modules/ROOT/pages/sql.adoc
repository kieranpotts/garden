= Structured query language (SQL)

Structured Query Language (SQL) is a programming language used for managing and manipulating xref:relational-databases.adoc[relational databases], allowing users to perform tasks such as querying data, defining database structure, and modifying data records.

SQL is used for two things:

* To define the structure of a database – its elements, attributes, and constraints.
* To insert, update, delete, and query data.
