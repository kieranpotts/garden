= User story

A short, conversational way to capture a
*xref:functional-requirements.adoc[functional requirement]*, as distinct from
the more structured *xref:use-case.adoc[use case]*.

The canonical template – "As a <role>, I want <capability>, so that <benefit>"
– often names a *xref:persona.adoc[persona]* as the role, tying the story to a
researched user rather than an abstract one.
