= Learnability

*Learnability* is the degree to which specified users can learn to use a product or system to achieve specified goals,
with effectiveness, efficiency, freedom from risk, and satisfaction, in a specified context of use. It is about how
quickly and confidently a new user builds a working mental model of a system, rather than how efficiently an
already-proficient user can operate it.

ISO/IEC 25010 classifies learnability as a sub-characteristic of xref:usability.adoc[*usability*], alongside
xref:operability.adoc[*operability*] and xref:user-error-protection.adoc[*user error protection*]. A system can be highly usable for an expert yet score poorly on learnability if it demands a steep initial investment (learning curve) before
that expertise pays off. The two attributes pull in the same general direction but are not identical.

Learnability is improved by consistent, predictable design, following established conventions so a user can transfer
knowledge from other systems, and by good onboarding, progressive disclosure of advanced features, and clear,
in-context feedback.

The xref:principle-of-least-astonishment.adoc[*principle of least astonishment*] is closely tied to learnability. A
system that behaves the way a user already expects is, by definition, easier to learn.
