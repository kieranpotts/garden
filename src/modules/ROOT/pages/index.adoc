= Digital Garden

:link-maggie-appleton: https://maggieappleton.com/garden-history
:link-garden-repo:     https://github.com/kieranpotts/garden

This is my digital garden. It's a sort of personal knowledgebase – a curated collection of notes and
reference materials for all sorts of topics within the field of computer science.

Like a regular garden, a digital garden needs careful planning and regular tending. You need to be
selective about what things you add to it and what you omit. You need to think about how everything
will be arranged. In time, new living documents may be planted, and older ones weeded out. It is a
perpetual work-in-progress. For more background, see {link-maggie-appleton}[Maggie Appleton's essay].

In my {link-garden-repo}[digital garden], my preference is for atomic documents formatted in AsciiDoc.
Each `.adoc` file is focused on a single idea or concept. Topics may cross-reference one another,
but otherwise each file is a self-contained document.

== Legend

* 🌱 *Seedling.* Early draft.
* 🌿 *Budding.* Needs attention.
* 🌳 *Evergreen.* Mature document.
* 🍂 *Decaying.* No longer maintained.
