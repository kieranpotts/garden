= Reasoning model

A *reasoning model* is a xref:large-language-model.adoc[*large language model*] that spends additional compute on an internal chain of thought – "thinking" – before and during its answer. Rather than emitting the answer directly, it first works through intermediate steps, checks them, and revises, and only then writes the visible response.

This improves results on problems with a verifiable chain of logic, such as mathematics, planning, multi-step analysis, and complex debugging. The cost is latency and token spend. The thinking is generated as output tokens, so it is billed even where the provider hides it from the user, and the response arrives later.

Most frontier models now combine both modes. The amount of reasoning is set per request with an xref:large-language-model.adoc[*effort*] setting, so one model can answer a trivial question quickly and spend a long time on a hard one. A reasoning model is a better fit than a fast one where correctness matters more than speed, and a worse fit for simple lookups and mechanical edits.

A visible chain of thought is not a faithful record of how the model reached its answer. It is generated by the same next-token prediction as everything else, so it should be treated as another output to verify, not as an audit trail. See xref:large-language-model.adoc[*large-language models → hallucinations*].
