= Compatibility

:link-iso25010: https://iso25000.com/index.php/en/iso-25000-standards/iso-25010

Compatibility is the degree to which a product, system, or component can exchange information with other products,
systems, or components, and/or perform its required functions, while sharing the same hardware or software
environment. It is a xref:quality-attribute.adoc[*quality attribute*] defined by ISO/IEC 25010, composed of two
sub-characteristics, xref:co-existence.adoc[*co-existence*] and xref:interoperability.adoc[*interoperability*].

The distinction between the two sub-characteristics matters. Co-existence is about not interfering with neighbors
while sharing an environment, whereas interoperability is about actively exchanging information and working together
with them. A system can have one without the other. For example, two applications that coexist peacefully on the
same server without ever exchanging any data.
