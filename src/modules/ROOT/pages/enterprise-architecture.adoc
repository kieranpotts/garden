= Enterprise architecture (EA)

Enterprise architecture frameworks such as *xref:togaf.adoc[TOGAF]* and
*xref:archimate.adoc[ArchiMate]* help organizations manage architecture
knowledge at scale. See
*xref:architectural-knowledge-management.adoc[architectural knowledge management]*.

EA encompasses the
*xref:enterprise-application-software.adoc[enterprise application software]*
portfolio an organization runs, alongside the business, data, and technology
architectures that support it.
