= Inheritance

Inheritance is a *xref:design-patterns.adoc[design pattern]* that is supported
by *xref:object-oriented-programming.adoc[object-oriented programming]*
languages. Inheritance allows a class to inherit properties and behaviors from
another class. This promotes code reuse and reduces
*xref:redundancy.adoc[redundancy]*.

Inheritance is best reserved for genuine subtyping, where a subclass truly is a
specialization of its parent and honors the
*xref:liskov-substitution-principle.adoc[Liskov substitution principle]*. For
reuse without an "is a" relationship, *xref:composition.adoc[composition]* is
usually the safer choice – it keeps *xref:coupling.adoc[coupling]* lower and
behaviors swappable at runtime.
