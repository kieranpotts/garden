= Inheritance

Inheritance is a xref:design-patterns.adoc[*design pattern*] that is supported by
xref:object-oriented-programming.adoc[*object-oriented programming*] languages. Inheritance allows a
class to inherit properties and behaviors from another class. This promotes
xref:code-reuse.adoc[*code reuse*] and reduces xref:redundancy.adoc[*redundancy*].

Inheritance is best reserved for genuine subtyping, where a subclass truly is a specialization of
its parent and honors the xref:liskov-substitution-principle.adoc[*Liskov substitution principle*].
For reuse without an "is a" relationship, xref:composition.adoc[*composition*] is usually the safer
choice – it keeps xref:coupling.adoc[*coupling*] lower and behaviors swappable at runtime.
Composition is a specialization of xref:association.adoc[*association*], the general class-to-class
relationship. Inheritance is also the mechanism Bertrand Meyer originally used to frame the
xref:open-closed-principle.adoc[*open-closed principle*]: a base class is closed to modification
because its clients depend on its fixed interface, yet open to extension through subclasses that add
or override behavior.
