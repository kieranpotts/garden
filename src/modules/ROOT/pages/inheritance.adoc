= Inheritance

Inheritance is a *xref:design-patterns.adoc[design pattern]* that is supported by *xref:object-oriented-programming.adoc[object-oriented programming]* languages. Inheritance allows a class to inherit properties and behaviors from another class. This promotes code reuse and reduces *xref:redundancy.adoc[redundancy]*.
