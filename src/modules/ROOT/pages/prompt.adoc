= Prompt

A *prompt* is an input supplied to a xref:large-language-model.adoc[*large language model*] to elicit a response. Most often it is text typed by a user, though it may also include images. A model does not consume a prompt as text. It is first encoded into tokens, and the tokens become the model's input.

The prompt a user types is only one part of the wider context assembled around it for each inference call. The harness adds a xref:context-engineering.adoc[*system prompt*], the instructions it injects at the start of every request, plus whatever else the task calls for, such as rule files, conversation history, and tool results. Together these make up the model's context, which is bounded by its xref:context-window.adoc[*context window*].

The practice of wording prompts to get better output is xref:prompt-engineering.adoc[*prompt engineering*]. Managing everything else that goes into the context is xref:context-engineering.adoc[*context engineering*]. (Treating the prompt as a program in its own right is the premise of xref:software-3-0.adoc[*Software 3.0*].)
