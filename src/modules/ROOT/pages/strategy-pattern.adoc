= Strategy pattern

// TODO: https://www.geeksforgeeks.org/system-design/strategy-pattern-set-1/

The strategy pattern is a *xref:design-patterns.adoc[design pattern]* used to
define a series of interchangeable algorithms that can be selected and changed
at runtime according to business needs. It allows an application to dynamically
adapt and apply different behaviors under different conditions.

For example, consider a logistics system that can use different shipping cost
calculation strategies depending on the region and urgency of the shipment. You
could have a `ShippingCalculationStrategy` interface with several
implementations like `StandardShipping`, `ExpressShipping`, and
`InternationalShipping`. The system can dynamically change the shipping
calculation strategy depending on the destination and delivery speed selected by
the customer.

The strategy pattern is a direct application of the
*xref:open-closed-principle.adoc[open-closed principle]*. A new algorithm is
added as a new strategy class, while the context that invokes the strategy is
closed to modification and never needs to be edited to accept it.
