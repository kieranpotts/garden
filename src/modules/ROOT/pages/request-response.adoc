= Request-response communication pattern

In request-response communication, a client sends a request directly to a
server, and the server sends a response back to the client. The client
initiates every exchange, so request-response is a *xref:pull-architecture.adoc[pull
architecture]* — the server only speaks when spoken to.

Implementations include RESTful HTTP APIs,
*xref:remote-procedure-call.adoc[RPC]*-style protocols such as
*xref:grpc.adoc[gRPC]*, and SOAP.
