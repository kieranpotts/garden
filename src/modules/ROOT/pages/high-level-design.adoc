= High-level design (HLD)

High-level design (HLD) focuses on the overall
*xref:architecture-and-design.adoc[architecture and design]* and structure of a
system, while low-level design (LLD) – the more granular end of
*xref:software-design.adoc[software design]* – provides detailed
specifications for individual components.

HLD provides the "big picture" view, outlining major components and their
interactions, while LLD defines the specific implementation details of each
component.

The *xref:c4-model.adoc[C4 model]*'s context and container levels correspond to
the high-level view, and its component and code levels to the low-level view.

See also *xref:bottom-up-design.adoc[bottom-up]* and *xref:top-down-design.adoc[top-down design]*.
