# Water

Researches an existing entry's topic afresh and extends the page with new material — like sow, but for a page that already exists.

## What it does

Given an existing entry, the agent reads it, researches the topic for depth and developments beyond what's already there, extends the page in place (staying on the same concept), adds cross-references, and may propose a maturity promotion. It's for growing established entries: rescuing a thin stub is `fertilize`'s job, and planting a brand-new entry is `sow`.

## How to invoke

> Water event-sourcing.adoc.

> Research and extend the resilience entry.

> Grow the CQRS page with more depth.
