# Water

Researches an established entry's topic afresh and extends the page with new
material — like sowing, but for a page that already exists.

## Interactivity

The agent is instructed to do as much work as possible
without blocking for input.
This workload can be run in the background away-from-keyboard.

## How to invoke

> Water event-sourcing.adoc.

> Research and extend the resilience entry.

> Grow the CQRS page with more depth, especially the trade-offs.

## Recommended models

A premium frontier reasoning model running in thinking mode is RECOMMENDED.
