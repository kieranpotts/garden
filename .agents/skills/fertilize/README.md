# Fertilize

Expands a thin stub entry into a fuller page, without changing what it's about.

## What it does

If you name a page, the agent expands that one. If you don't, the agent scans
the garden for the weakest stub and proposes one to work on — the one with the
most `// TODO` markers and the fewest cross-references, for example. The agent
researches the topic and writes proposed content, and may propose promoting the
entry to a new level of maturity, eg. from seedling 🌱 to budding 🌿.

## How to invoke

> Fertilize the abstraction entry.

> This entry needs more growth.

> Find the weakest stub in the garden and fertilize it.
