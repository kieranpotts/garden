# Fertilize

Brings a thin stub entry up to strength, without changing what it's about.

## Interactivity

The agent is instructed to do as much work as possible without blocking for input.
This workload can be run in the background away-from-keyboard.

## How to invoke

> Fertilize the abstraction entry.

> This entry needs more growth.

> Find the weakest stub in the garden and fertilize it.

## Recommended models

A premium frontier reasoning model running in thinking mode is RECOMMENDED.
