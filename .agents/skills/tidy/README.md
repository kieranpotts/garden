# Tidy

Reviews a single entry against the style guide and fixes mechanical style
violations directly.

## Interactivity

The agent is instructed to do as much work as possible without blocking for input.
This workload can be run in the background away-from-keyboard.

## How to invoke

> Tidy resilience.adoc.

> Check style on this entry.

> Give agent.adoc a style-guide pass.

## Recommended models

A mid-tier model is sufficient.
