# Entwine

Given a single garden entry, finds other entries related to it but not
cross-referenced, and adds the missing `xref:` links.

## Interactivity

The agent is instructed to do as much work as possible
without blocking for input.
This workload can be run in the background away-from-keyboard.

## How to invoke

> Entwine event-sourcing.adoc with its neighbors.

> Link this page to related entries.

> Is retry.adoc properly connected to its siblings?

## Recommended models

A premium frontier reasoning model running in thinking mode is RECOMMENDED.
