# Cultivate

Reads one target entry and triages it, recommending which skills — watering,
fertilizing, dividing, entwining, tending, tidying, pruning, grafting, or
uprooting — would improve it, with a one-line reason per recommendation.

## Interactivity

The agent is instructed to do as much work as possible without blocking for input.
This workload can be run in the background away-from-keyboard.

## How to invoke

> Cultivate event-sourcing.adoc.

> What does this entry need?

> Give me a triage of the resilience entry.

## Recommended models

A mid-tier model is sufficient.
