# Garden skills

Agent skills for maintaining this digital garden. Each does one focused task.

| Skill | Summary |
| --- | --- |
| [sow](./sow/README.md) | Research a new topic and plant it as a new entry, cross-referenced to relevant adjacent topics. |
| [tend](./tend/README.md) | Find broken cross-references, fake pseudo-links, orphaned pages, and stale maturity labels. |
| [fertilize](./fertilize/README.md) | Expand a thin stub entry into a fuller page, without changing its scope. |
| [prune](./prune/README.md) | Check whether a single entry duplicates an existing page, and if so merge them into one surviving page. |
| [graft](./graft/README.md) | Merge two or more related-but-distinct entries into a single broader page. |
| [split](./split/README.md) | Split an overgrown entry that's drifted into covering multiple concepts back into separate atomic pages. |
| [entwine](./entwine/README.md) | Given a single entry, find other pages related to it but not cross-referenced, and add the missing links. |
| [forage](./forage/README.md) | Find topics referenced or implied across the garden that don't have a page yet, ranked by mention frequency, for sowing. |
| [harvest](./harvest/README.md) | Produce a digest of recent garden activity — what's been sown, fertilized, tended, pruned, grafted, or entwined. |
| [cultivate](./cultivate/README.md) | Review a single entry against the style guide and fix mechanical style violations: dashes, colons, casing, bold-text usage. |
| [trim](./trim/README.md) | Freeform general gardening — trim waffle, smooth phrasing, move things about, drop repetition — small inline improvements within a page. |

See each skill's own `SKILL.md` for the full instructions an agent follows, and `README.md` for invocation examples.
