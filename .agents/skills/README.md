# Garden skills

Agent skills for maintaining this digital garden. Each does one focused task.

| Skill | Summary |
| --- | --- |
| [cultivate](./cultivate/README.md) | Review a topic against the style guide and fix mechanical style violations. |
| [entwine](./entwine/README.md) | Given a topic, find other topics related to it and add the missing cross-references. |
| [fertilize](./fertilize/README.md) | Expand a thin stub entry into a fuller document, without changing its scope. |
| [forage](./forage/README.md) | Find topics referenced or implied across the garden that don't have a document yet. |
| [graft](./graft/README.md) | Merge two or more related topics into a single, broad document. |
| [harvest](./harvest/README.md) | Produce a digest of the fruits of recent garden activity. |
| [prune](./prune/README.md) | Drop a document who's topic is already covered elsewhere. |
| [sow](./sow/README.md) | Research a new topic and plant it as a new document. |
| [split](./split/README.md) | Split an overgrown document that's drifted into covering multiple topics. |
| [tend](./tend/README.md) | Find broken cross-references, fake pseudo-links, orphaned pages, and stale maturity labels. |
| [trim](./trim/README.md) | Trim waffle, smooth phrasing, drop repetition, and other small improvements within a topic. |
| [water](./water/README.md) | Research an existing topic afresh, and extend it with new depth and developments. |

See each skill's own `SKILL.md` for the full instructions an agent follows, and
`README.md` for invocation examples.
