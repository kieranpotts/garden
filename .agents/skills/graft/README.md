# Graft

Splits an overgrown garden entry that covers more than one concept into separate atomic pages, cross-referenced.

## What it does

Given a page that's drifted into covering multiple ideas, the agent proposes a split, confirms it with you, creates a new atomic page per split-out concept, narrows the original, and links everything together — checking first that no split-out concept already has its own page elsewhere (which would be a job for `/prune` instead).

## How to invoke

> Graft event-driven-architecture.adoc — it's covering both event sourcing and CQRS.

> This entry has grown to cover two ideas, split it.
