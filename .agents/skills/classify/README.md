# Classify

Compares one target entry against its maturity emoji in the index and reports
whether the two still agree — a substantial, well-linked 🌱 Seedling ready for
promotion, or a 🌿 Budding or 🌳 Evergreen entry that has thinned or gone
stale. Maturity is an editorial call the user makes, so this skill only ever
recommends; it never changes the emoji.

## Interactivity

The agent is instructed to do as much work as possible without blocking for
input. This workload can be run in the background away-from-keyboard.

## How to invoke

> Classify event-sourcing.adoc.

> Is the resilience entry still a seedling?

> Check the maturity of circuit-breaker.adoc.

## Recommended models

A mid-tier model is sufficient.
