# Forage

Finds topics that are referenced or implied across the garden but have no entry
of their own, and produces a ranked list of candidates worth planting.

## Interactivity

The agent is instructed to do as much work as possible without blocking for input.
This workload can be run in the background away-from-keyboard.

## How to invoke

> Forage the garden.

> What topics are missing?

> Forage around the AI topics.

## Recommended models

A mid-tier model is sufficient.
